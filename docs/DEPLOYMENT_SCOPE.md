# Deployment Scope

This repository does not claim to release the complete proprietary board-level copy-avoidance pipeline. Vendor-specific and internal deployment wrappers are excluded. Included RKNN or TensorRT examples are labeled according to their actual scope.

DenseScout v0.1 exposes the selector frontend and public evaluation tools. Downstream detector closure, NanoDet, DPR, RKNN, TensorRT, and board-specific copy-avoidance pipelines are outside the supported public core unless explicitly documented in `optional/`.
